# AI Developer Workspace & Workflow Suite

An interactive AI code analysis and prompt engineering workspace application built with **React 19**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## 🌟 Key Features

- **Preset AI Workflows**: Refactor code, generate automated unit tests, and build API specs.
- **Custom Prompt Playground**: Execute live AI code inspection queries.
- **Terminal Sandbox**: Code window output with one-click clipboard copying.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/pradippantha31/ai-developer-suite.git

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
