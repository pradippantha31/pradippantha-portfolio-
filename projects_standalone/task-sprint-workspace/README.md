# Task & Sprint Coordination Workspace

An interactive Agile Kanban workspace application built with **React 19**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## 🌟 Key Features

- **4-Phase Kanban Board**: `To Do`, `In Progress`, `In Review`, `Completed`.
- **Sprint Velocity Tracker**: Real-time progress percentage based on completed task cards.
- **Dynamic Task Creator**: Assign task title, assignee, and priority badge (_High_, _Medium_, _Low_).
- **One-Click Phase Transitions**: Move task cards across workflow phases effortlessly.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/pradippantha31/task-sprint-workspace.git

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
