# Expense Tracking App (Full Stack / SaaS)

An intuitive, modern SaaS expense management application built with **React 19**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## 🌟 Key Features

- **Live Budget Statistics**: Real-time total spent, remaining balance, and usage percentage meter.
- **Dynamic Expense Management**: Add and delete transactions with instant calculation updates.
- **Category Filtering**: Tabbed filtering by categories (_Infrastructure_, _Design_, _Domain_, _Team_).
- **Agile Sprint Workflow**: Integrated Project Manager notes and sprint milestones (2025).

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/pradippantha31/expense-tracking-app.git

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
